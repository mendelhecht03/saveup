# Current SaveUp state

Updated November 3, 2026.

* **One app:** `lite/` (SaveUp Lite). Plaid Sandbox only. Includes the weekly inbox, transfer verification, budgets with pending stripes and true over-100% display, hand-logged purchases that verify against bank charges, planned purchases, history, and a Sandbox test lab for custom charges.
* **In progress:** [issue #5](https://github.com/mendelhecht03/saveup/issues/5), redrawing the whole interface to match `docs/design/` and finishing budgets, Plaid Sandbox test banks and receipt scanning. One pull request per milestone. The plan and progress live in comments on that issue. Milestone 1 (audit and plan) is done.
* **Decided:** "Essential" is a priority tag, not a budget category (Mendel, Nov 3, 2026).
* **Archived (reference only):** `archive/codex-mvp` holds the earlier `mvp/` app, including unfinished receipt scanning, manual entry, and Plaid Production (real bank) setup, plus the original mock-data `prototype/`. `archive/initial-setup` holds the first setup branch.
* **Deferred:** real bank connections, AI assistant and MCP, email receipts, live price tracking, visualizations.
