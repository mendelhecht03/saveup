# Current SaveUp state

Updated November 3, 2026.

* **One app:** `lite/` (SaveUp Lite). Plaid Sandbox only. Redrawn on one design system (Friendly Spatial). Includes the weekly inbox queue (swipe right confirms a suggestion, swipe left scans a receipt), transfer purposes, budgets with pending stripes and true over-100% display, AI budget suggestions (needs `ANTHROPIC_API_KEY`), hand-logged purchases that verify against bank charges, planned purchases, history, a Sandbox test lab and `npm run seed` for the SaveUp Test Bank. Data is stored in SQLite.
* **In progress:** [issue #5](https://github.com/mendelhecht03/saveup/issues/5), redrawing the whole interface to match `docs/design/` and finishing budgets, Plaid Sandbox test banks and receipt scanning. One pull request per milestone. The plan and progress live in comments on that issue. Milestones 1–4 are merged (plan, design system and shell, Sandbox test banks, budgets and inbox with SQLite and AI suggestions). Milestone 5 (receipt scanning and matching) and milestone 6 (preview screens, weekly review, what-if) are built and waiting to be merged. Milestone 7 (real 3D icons) waits on Mendel's images. Reading real receipt photos and AI suggestions need `ANTHROPIC_API_KEY`, which Mendel hasn't added yet.
* **Decided:** "Essential" is a priority tag, not a budget category. Suggested budgets look different from confirmed ones. Swipe right confirms, swipe left scans a receipt (Mendel, Nov 3, 2026).
* **Archived (reference only):** `archive/codex-mvp` holds the earlier `mvp/` app, including unfinished receipt scanning, manual entry, and Plaid Production (real bank) setup, plus the original mock-data `prototype/`. `archive/initial-setup` holds the first setup branch.
* **Deferred:** real bank connections, AI assistant and MCP, email receipts, live price tracking, visualizations.
